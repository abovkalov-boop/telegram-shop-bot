# 🛍 Telegram-бот интернет-магазина (aiogram 3)

Бот с каталогом, корзиной, оформлением заказа, уведомлением администратора
и заглушкой оплаты LiqPay. Товары и категории хранятся в SQLite.

## Возможности

- 🛍 **Каталог** по категориям — карточки товаров с фото, описанием и ценой
- 🛒 **Корзина** — добавление, удаление позиций, очистка, подсчёт суммы
- ✅ **Оформление заказа** — имя, телефон (кнопкой или вручную), адрес доставки
- 🔔 **Уведомление админу** — с деталями заказа и кнопками «Принять / Отклонить»
- 💳 **LiqPay** — заглушка с генерацией подписи и инструкцией подключения

## Структура проекта

```
shop_bot/
├── bot.py                # точка входа (polling)
├── config.py             # загрузка .env
├── keyboards.py          # inline / reply клавиатуры
├── requirements.txt
├── .env.example          # шаблон переменных окружения
├── database/
│   ├── db.py             # схема + все запросы (aiosqlite)
│   └── seed.py           # демо-каталог для первого запуска
├── handlers/
│   ├── start.py          # /start, /help, меню
│   ├── catalog.py        # категории и товары
│   ├── cart.py           # корзина
│   └── order.py          # оформление (FSM), оплата, действия админа
└── services/
    └── liqpay.py         # интеграция LiqPay (заглушка)
```

## Установка и запуск

```bash
cd shop_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# отредактируйте .env: BOT_TOKEN и ADMIN_ID обязательны

python bot.py
```

При первом запуске создаётся `shop.db` и наполняется демо-товарами
(см. `database/seed.py`). Чтобы пересоздать каталог — удалите `shop.db`.

## Переменные окружения (`.env`)

| Переменная            | Назначение                                  |
|-----------------------|---------------------------------------------|
| `BOT_TOKEN`           | Токен от [@BotFather](https://t.me/BotFather) |
| `ADMIN_ID`            | Telegram ID админа (узнать: @userinfobot)   |
| `LIQPAY_PUBLIC_KEY`   | Публичный ключ LiqPay (для боевой оплаты)   |
| `LIQPAY_PRIVATE_KEY`  | Приватный ключ LiqPay                       |

> ⚠️ Чтобы админ получал уведомления, он должен **написать боту `/start`**
> хотя бы один раз (иначе Telegram не даст боту отправить ему сообщение).

## Подключение реальной оплаты LiqPay

Сейчас оплата — заглушка (`services/liqpay.py`): подпись формируется по
официальному алгоритму, но списание не выполняется. Чтобы включить боевой режим:

1. Зарегистрируйтесь на <https://www.liqpay.ua>, создайте магазин, получите ключи.
2. Пропишите `LIQPAY_PUBLIC_KEY` / `LIQPAY_PRIVATE_KEY` в `.env`.
3. Поднимите публичный **HTTPS-эндпоинт** для callback (aiohttp/FastAPI),
   куда LiqPay пришлёт результат оплаты; в нём проверьте подпись и вызовите
   `database.db.set_order_status(order_id, "paid")`.
4. Отдавайте пользователю checkout-форму LiqPay (URL `checkout` + `data` + `signature`),
   например через кнопку-ссылку или Telegram WebApp.

Подробности и ссылки на документацию — в комментариях `services/liqpay.py`.

## Как добавить свои товары

Отредактируйте `database/seed.py` **до первого запуска**, либо добавляйте
записи в таблицы `categories` / `products` напрямую в `shop.db`
(например, через `sqlite3 shop.db`). Поле `photo` — URL картинки или Telegram `file_id`.
